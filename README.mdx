# TravelTech IROPS

**TravelTech IROPS** — проектная документация и прототип микросервисной системы для отслеживания сбоев рейсов и автоматического перепланирования поездок (кейс «Альфред, друг Бэтмена»).

## 🧩 Что делает система

- Отслеживает статус рейсов через внешние API
- При задержке/отмене уведомляет пользователя
- Предлагает альтернативные рейсы, отели или активности
- Обновляет план путешествия
- Учитывает багаж, визы и таймзоны
- Паспортные данные удаляются через 30 дней после поездки

## 🏗️ Архитектура

**Микросервисы**:

- **Flight Tracker** — опрос внешних API, отправка событий в Kafka
- **Trip Service** — управление поездками, проверка стыковок, принятие решений
- **Alternative Service** — поиск альтернатив (рейсы, отели, активности)
- **Notification Service** — отправка уведомлений (Push/Email/SMS)
- **Payment Service** — обработка платежей
- **Analytics Service** — сбор метрик, отправка в ML-модель
- **API Gateway** — единая точка входа, аутентификация, маршрутизация

**Инфраструктура**:

- PostgreSQL — основная БД
- Redis — кеш статусов
- Kafka — очередь событий
- Docker — контейнеризация
