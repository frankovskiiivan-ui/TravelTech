**TravelTech IROPS** (Irregular Operations) — это проектная документация и работающий прототип микросервисной системы для отслеживания сбоев рейсов и автоматического перепланирования поездки.

## 🎯 Цель проекта

Разработать систему, которая:
- ✅ Отслеживает статус рейсов через внешние API
- ✅ При задержке/отмене уведомляет пользователя
- ✅ Автоматически предлагает альтернативные рейсы, отели или активности
- ✅ Обновляет общий план путешествия
- ✅ Учитывает багаж, визы и таймзоны
- ✅ Не хранит паспортные данные дольше необходимого
