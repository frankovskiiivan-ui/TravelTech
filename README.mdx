# TravelTech Backend

Система оркестрации и обработки поездок (Trip Orchestration) для TravelTech-платформы.  
Проект реализует логику диспетчеризации: поиск альтернатив, обработка статусов рейсов, оплата и уведомления через Kafka.

**Стек:** Python, FastAPI (сервисный слой), SQLAlchemy, asyncpg, Redis, Kafka, Airflow (оркестрация DAG), Apache Spark (обработка данных), PostgreSQL.

## 🗺 Архитектура в двух словах

TravelTech построен по принципу разделения ответственности:

- **Оркестрационный слой (TripServiceDispatcher)** — чистая логика принятия решений, вызова адаптеров, записи в БД и публикации событий. Используется в Airflow DAG и Spark-задачах.
- **Сервисный слой (FastAPI + Kafka Consumer)** — HTTP API для внешних клиентов и фоновая обработка событий о задержках рейсов.
- **Shared-компоненты** — клиенты, логирование, утилиты.

Такая структура позволяет запускать тяжёлые пайплайны (Spark/Airflow) отдельно от онлайн‑сервиса, а также легко подключать новые адаптеры (авиа, отели, платежи).

## 🔄 Поток данных

1. **Клиент** → отправляет запрос в **API Gateway**
2. **API Gateway** → маршрутизирует в **Trip Service** или **Flight Tracker**
3. **Trip Service (Dispatcher)**:
   - Через **External Adapters** обращается к внешним API
   - Сохраняет результат в **PostgreSQL**
   - Кэширует статусы в **Redis**
   - Публикует событие в **Kafka** (топик `trip_events`)
4. **Notification Service** ← слушает Kafka:
   - Получает событие
   - Обращается к **Recommendation Service** за персонализацией
   - Отправляет уведомление через **Push / Email / SMS**

### 🚨 Обработка задержек рейсов

Особый сценарий — когда Flight Tracker присылает событие о задержке:

```
Flight Tracker → Kafka (flight_status)
                      ↓
              Trip Service (Dispatcher)
                      ↓
        Проверка стыковки (connection_time - delay_minutes)
                      ↓
         ┌────────────┴────────────┐
         ▼                         ▼
  Стыковка OK              Стыковка нарушена
         │                         │
         ▼                         ▼
  Уведомить о задержке    Найти альтернативу
                                   │
                        ┌──────────┴──────────┐
                        ▼                     ▼
                  Альтернатива есть     Альтернативы нет
                        │                     │
                        ▼                     ▼
              Обновить маршрут       Уведомить о задержке
              Уведомить юзера        без альтернативы
```

## 📨 События Kafka

### Топик `trip_events`

| Событие | Когда отправляется | Payload |
|---|---|---|
| `offer_created` | После успешного поиска | `trip_id`, `user_id`, `offers_count` |
| `payment_success` | После успешной оплаты | `trip_id`, `user_id`, `transaction_id` |
| `payment_failed` | При ошибке оплаты | `trip_id`, `user_id`, `reason` |
| `trip_confirmed` | Пользователь принял альтернативу | `trip_id`, `user_id`, `selected_flight` |
| `trip_declined` | Пользователь отклонил альтернативу | `trip_id`, `user_id` |
| `trip_updated` | Маршрут обновлен автоматически | `trip_id`, `user_id`, `old_flight`, `new_flight` |
| `flight_delayed` | Рейс задержан (стыковка OK) | `trip_id`, `flight_id`, `delay_minutes` |
| `flight_delayed_no_alternative` | Задержка, альтернативы нет | `trip_id`, `flight_id`, `delay_minutes` |

## 🗄 Модели данных (PostgreSQL)

### `trips`
| Поле | Тип | Описание |
|---|---|---|
| `id` | String (PK) | ID поездки |
| `user_id` | String | ID пользователя |
| `status` | String | `active`, `updated`, `confirmed`, `paid`, `declined` |
| `start_date` | DateTime | Дата начала |
| `end_date` | DateTime | Дата окончания |
| `created_at` | DateTime | Создано |
| `updated_at` | DateTime | Обновлено |

### `trip_flights`
| Поле | Тип | Описание |
|---|---|---|
| `id` | String (PK) | ID рейса |
| `trip_id` | String (FK) | ID поездки |
| `flight_number` | String | Номер рейса |
| `airline` | String | Авиакомпания |
| `departure` | DateTime | Вылет |
| `arrival` | DateTime | Прилет |
| `status` | String | `scheduled`, `delayed`, `replaced` |
| `baggage` | Boolean | Наличие багажа |
| `visa_required` | Boolean | Требуется ли виза |

### `trip_decisions`
| Поле | Тип | Описание |
|---|---|---|
| `id` | UUID (PK) | ID решения |
| `trip_id` | String (FK) | ID поездки |
| `user_id` | String | ID пользователя |
| `decision` | String | `accept` / `decline` |
| `selected_flight` | String | Выбранный рейс (если `accept`) |
| `made_at` | DateTime | Когда принято |

### `trip_changes`
История изменений маршрута (для аудита и аналитики).
