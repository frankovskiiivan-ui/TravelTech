# TravelTech Backend

Система оркестрации и обработки поездок (Trip Orchestration) для TravelTech-платформы. Принцип - диспетчеризация: поиск альтернатив, обработка статусов рейсов, оплата и уведомления через Kafka.

**Стек:** Python · FastAPI · Uvicorn · Pydantic · httpx · asyncio · HTML5 · CSS3 · Vanilla JS · SQLite (mock) · in-memory cache (mock) · asyncio.Queue (mock Kafka) · AirLabs API · StayingAPI 

## Архитектура 

TravelTech построен по принципу разделения ответственности:

- **Оркестрационный слой (TripServiceDispatcher)** — чистая логика принятия решений, вызова адаптеров, записи в БД и публикации событий. Используется в Airflow DAG и Spark-задачах.
- **Сервисный слой (FastAPI + Kafka Consumer)** — HTTP API для внешних клиентов и фоновая обработка событий о задержках рейсов.
- **Shared-компоненты** — клиенты, логирование, утилиты.

Такая структура позволяет запускать тяжёлые пайплайны (Spark/Airflow) отдельно от онлайн‑сервиса, а также легко подключать новые адаптеры (авиа, отели, платежи).

## Быстрый старт

### Предварительные требования

- **Python** 3.11+ 

### 1. Клонирование репозитория

```bash
git clone https://github.com/frankovskiiivan-ui/TravelTech.git
cd TravelTech
```

### 2. Виртуальное окружение

```bash
python -m venv .venv

```

### 3. Установка зависимостей

```bash
pip install fastapi "uvicorn[standard]" httpx
```

### 4. Настройка окружения

```bash
cp .env.example .env
```

### 5. Запуск инфраструктуры

```bash
uvicorn services.api_gateway.main:app --reload --port 8000
```

### 6. Открыть в браузере 

```
http://localhost:8000
```


### 7. Проверка работы 

```bash
curl -X POST http://localhost:8000/api/search-flights \
  -H "Content-Type: application/json" \
  -d '{"city_from": "SPU", "city_to": "LHR", "date": "2026-10-20"}'
```
