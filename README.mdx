**TravelTech IROPS** (Irregular Operations) — это проектная документация и работающий прототип микросервисной системы для отслеживания сбоев рейсов и автоматического перепланирования поездки.

## 🎯 Цель проекта

Разработать систему, которая:
- ✅ Отслеживает статус рейсов через внешние API
- ✅ При задержке/отмене уведомляет пользователя
- ✅ Автоматически предлагает альтернативные рейсы, отели или активности
- ✅ Обновляет общий план путешествия
- ✅ Учитывает багаж, визы и таймзоны
- ✅ Не хранит паспортные данные дольше необходимого

# 🔧 Микросервисы

## Trip Service (Диспетчер)

**Роль**: Центральный управляющий сервис, принимающий решения.

**Ключевые функции**:
- Хранение и управление планом поездки
- Проверка стыковок
- Вызов Alternative Service при нарушении стыковки
- Обработка решений пользователя
- Отправка событий в Kafka

**Технологии**: Python, FastAPI, SQLAlchemy, asyncpg

**Эндпоинты**:
- `GET /api/v1/trips/{trip_id}/status` — получить статус поездки
- `POST /api/v1/trips/{trip_id}/decide` — принять решение

**Пример кода (Dispatcher)**:
```python
async def handle_flight_status(self, event: Dict[str, Any]):
    flight_id = event.get("flight_id")
    new_status = event.get("status")
    delay_minutes = event.get("delay_minutes", 0)
    
    # 1. Найти поездку
    trip = await self._find_trip_by_flight(flight_id)
    
    # 2. Проверить стыковку
    next_flight = await self._get_next_flight(trip.id, flight_id)
    if next_flight and self._is_connection_broken(next_flight, delay_minutes):
        # 3. Запросить альтернативу
        alternative = await self._request_alternative(trip, flight_id)
        # 4. Обновить маршрут
        await self._update_trip_with_alternative(trip, flight_id, alternative)
        # 5. Отправить уведомление
        await self._notify_trip_updated(trip, alternative)
